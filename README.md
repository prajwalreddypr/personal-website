# Developer Portfolio

This is my professional portfolio website showcasing my skills, projects, and experience as a software developer.

## Features

- Responsive design
- Clean, modern UI
- Sections for About, Skills, Projects, Education, and more
- Contact form
- Downloadable CV

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts

## Setup

1. Clone this repository
2. Open `index.html` in your browser

## Customization

1. Replace `assets/images/profile.jpg` with your photo
2. Replace `assets/resume.pdf` with your CV
3. Update all personal information in `index.html`
4. Add your real projects to the Projects section
5. Update social media links with your profiles

## Deployment

This portfolio is deployed using GitHub Pages. To deploy your own:

1. Push this repository to your GitHub account
2. Go to Settings > Pages
3. Select the main branch as the source
4. Your site will be published at `https://<your-username>.github.io/<repository-name>/`
